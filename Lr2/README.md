# Лабораторная работа №2 (Вариант 15)

## Задание 1: Класс SIGN
Реализован класс `SIGN` (наследник `Person`), содержащий поля: фамилия, имя, знак зодиака и дата рождения (массив из трех чисел).
Выполнены требования:
- Динамическое выделение памяти (без использования STL контейнеров).
- Перегрузка операторов ввода/вывода (`>>`, `<<`).
- Пользовательское меню: добавление, вставка, удаление, редактирование, сортировка по дате, поиск по фамилии.
- Обработка исключений (exceptions).

## Задание 2: Файловые и строковые потоки
Программа считывает текст из файла, находит самое длинное слово и подсчитывает количество его вхождений.

## Сборка и запуск
Проект собран в Visual Studio. Для запуска откройте файл решения `.sln` и нажмите F5.
